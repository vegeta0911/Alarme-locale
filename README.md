# alarme-locale

Binaires precompiles (PyInstaller --onefile) du demon `myfox_local_server.py`.

Ce depot ne contient **aucun code source** -- uniquement des binaires Linux prets a l'emploi
(x86_64, aarch64, armv7l), publies automatiquement a chaque nouvelle version par le workflow
GitHub Actions du depot source (prive). Telecharges par le plugin Jeedom "AlarmeMyfox" via le
bouton "Installer les dependances", sans configuration ni jeton necessaire.

Voir la derniere release pour les binaires : https://github.com/vegeta0911/alarme-locale/releases/latest
